# Emre Doğum Günü Sürpriz Web Sayfası 🎉

Arkadaşınız Emre için hazırlanan mobil uyumlu interaktif sürpriz web sayfası.

## 🚀 Nasıl Çalışır?
1. Sayfa ilk açıldığında beyaz arka planda:
   - Ortada büyük fontla: **"Sol üste bak"**
   - Sol üstte: **"Sağ alta bak"**
   - Sağ altta: **"BAS"** butonu (dikkat çeken tatlı bir animasyonla)
2. **"BAS"** butonuna tıklandığında:
   - Tüm yönlendirme yazıları ve buton pürüzsüz bir şekilde yok olur.
   - Doğum günü jingle melodisi çalar.
   - Ekranı kaplayan renkli konfeti patlaması başlar.
   - Emre'nin fotoğrafı 3D Polaroid çerçeve efektiyle öne doğru fırlar ve altında **"İyi ki doğdun Emre! 🎉"** kutlama mesajı görünür.

---

## 🎬 Video veya Fotoğrafı Ekleme

Sayfa hem **video** hem de **fotoğraf** destekler! 

### Video Kullanmak İçin (Önerilen 🎥):
- Arkadaşınızın videosunu `video.mp4` (veya `.mov`, `.webm`) adıyla şu klasöre koyun:
  📁 `dogum-gunu-emre/video.mp4`
- Butona basıldığında video otomatik olarak sesli başlar ve oynatıcı kontrolleri görünür!

### Fotoğraf Kullanmak İçin 📸:
- Eğer video yerine fotoğraf koymak isterseniz, fotoğrafınızı `foto.jpg` adıyla klasöre atmanız yeterlidir.
- Sayfa otomatik olarak videonun olmadığını anlar ve fotoğrafı neşeli doğum günü melodisiyle birlikte açar.

## 🌐 GitHub Pages ile Canlıya Alma (Adım Adım)

1. [GitHub](https://github.com)'a giriş yapın ve sağ üstteki **+** ikonuna tıklayıp **New repository** deyin.
2. Repository name kısmına örneğin: `emre-dogum-gunu` yazın. **Public** seçin ve **Create repository** butonuna basın.
3. Bu klasördeki dosyaları (`index.html`, `foto.jpg`, `placeholder.svg`) GitHub repo'nuza yükleyin:
   - GitHub sayfasındaki **"uploading an existing file"** linkine tıklayın ve dosyaları sürükleyip bırakın, ardından **Commit changes** deyin.
4. Repo sayfasında üstteki **Settings** (Ayarlar) sekmesine gidin.
5. Soldaki menüden **Pages** seçeneğine tıklayın.
6. **Branch** kısmında `None` yerine `main` (veya `master`) seçip klasörü `/ (root)` olarak bırakıp **Save** deyin.
7. Yaklaşık 1-2 dakika içinde size şu şekilde bir canlı link verecektir:
   `https://kullaniciadiniz.github.io/emre-dogum-gunu/`

Bu linki WhatsApp'tan veya mesajla Emre'ye atıp arkasından tepkisini izleyebilirsiniz! 🥳
